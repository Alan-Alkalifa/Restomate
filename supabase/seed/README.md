# Seed assets

## Demo menu sample images (`menu-images/`)

Six small PNGs (480x320, each well under 100 KB) used by the seeded Demo Restaurant menu.

- **Origin:** generated by `generate-menu-images.py` (this folder) (pure Python standard library). They are simple abstract
  illustrations, not photographs, and contain no third-party artwork, fonts or code.
- **Licence:** dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Use them anywhere.
- **Layout:** `<organization_id>/items/<item_id>/sample.png`, the same shape the app uses for uploads, so
  `menu_items.image_path` points straight at them. The ids are the fixed Demo ids in `supabase/seed.sql`.
- **How they get into Storage:** `supabase/config.toml` declares `[storage.buckets.menu-images]` with
  `objects_path = "./seed/menu-images"`; the Supabase CLI uploads this folder when the local stack starts / resets.
  This README lives one level up so that only image files are uploaded.
